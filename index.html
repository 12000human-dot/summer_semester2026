수강신청 방법
  • 가. 수강신청 방법
    홈페이지 → 학번, 공동인증서, 네이버인증서 로그인 중 선택
    인증서 로그인: '강의보기·시험응시'에 필수
  • 나. 수강신청 위치
    마이페이지 → 내학사관리 → 수강신청
  • 다. 수강순서: 전공과목 및 졸업필수 학점 우선 선택
  • 라. 주/연계/복수/부 전공과목의 이수구분 체크 (단일전공 제외)
  • 마. 과목 선택 후 [임시저장] → 하단 [나의 수강신청현황] 확인
  • 바. 최종 [수강신청완료] 버튼 클릭 시 확정됨
⭐
졸업학기 학생: '전공필수/선택, 교양필수/선택' 학점 부족하지 않도록
일반선택보다 전공필수/선택 또는 교양필수/선택을 우선 이수하세요.
